# 02 - Design System

# Engineering Portfolio Visual System


---

# 1. Design Philosophy


The design system follows:

Minimal

Industrial

Futuristic

Engineering Precision

Every element should feel like:

A professional technology product interface.


---

# 2. Color System


## Background Colors


### Primary Background

#0B1220

Usage:

- Section transition
- Cards
- Panels


---

## Primary Accent


### Technology Cyan

#00E5FF



Usage:

- Buttons
- Highlights
- Interactive elements
- Data visualization


---

## Secondary Accent


### Future Green

#7CF7D4



Usage:

- Status indicators
- Small highlights


---

## Text Colors


Primary:

#FFFFFF

Secondary:

#A8B2C1

#667085

# 8. Card Design


Cards should feel like:

Engineering interface panels.


Properties:


Background:

rgba(255,255,255,0.05)

Border:

1px solid rgba(255,255,255,0.1)

Radius:

20px

Shadow:

Very subtle.


Avoid:

Heavy shadows.


---

# 9. Glass Effect Rules


Glassmorphism should be limited.


Allowed:

- Navigation
- Small information panels


Avoid:

Entire website becoming glass.


---

# 10. Button Style


Primary Button:

Background:
#00E5FF

Text:
#05070A

Shape:

Rounded Rectangle

Radius: 999px

Hover:

Scale 1.05

Glow Effect

---

# 11. Border Style


Engineering feeling:


Use:

Thin lines

Technical separators

Blueprint grid

Avoid:

Thick borders

---

# 12. Icon Style


Use:


- Minimal line icons
- Technical symbols


Avoid:


- Colorful emoji icons
- Cartoon illustrations


---

# 13. Image Treatment


Images should have:


- Dark overlay
- Cinematic contrast
- Soft lighting


---

# 14. Motion Principle


Animation should feel:

Slow

Controlled

Mechanical

Precise

Avoid:

Fast

Bouncy

Playful

---

# 15. Final Design Rule


Every component must answer:


"Does this look like it belongs in a future engineering laboratory?"


If not:

Remove it.
