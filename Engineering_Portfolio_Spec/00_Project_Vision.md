# 00 - Project Vision

# Engineering Portfolio Vision

## Yu Jen Lin

## Building Intelligent Machines for the Future


---

# 1. Website Identity


This website represents the personal engineering identity of:

**Yu Jen Lin**

A robotics and intelligent automation engineering student focused on:

- Robotics
- Embedded Systems
- AI Applications
- Digital Manufacturing
- Automation Technology


The website should communicate:

"I design, build, and improve intelligent systems."


---

# 2. Brand Positioning


## Current Problem

Many student portfolios are:

- Static
- Text-heavy
- Template-based
- Similar to resumes


This portfolio should be different.


Instead of showing only information:

The website should create an experience.


The visitor should experience:

Engineering.

Technology.

Innovation.


---

# 3. Design Statement


## Main Statement


> Building Intelligent Machines for the Future.


This sentence represents:

## Building

Hands-on engineering ability.

Examples:

- Robot development
- Rocket project
- Embedded systems


## Intelligent

The combination of:

- AI
- Sensors
- Data Processing
- Automation


## Machines

Physical engineering:

- Robotics
- Mechanical design
- Manufacturing


## Future

Global engineering vision:

- International collaboration
- Smart manufacturing
- Digital transformation

The website succeeds when:


- The visitor remembers the drone experience
- Projects feel meaningful
- Engineering ability is obvious
- The design feels professional
