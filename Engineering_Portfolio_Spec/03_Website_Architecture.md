# 03 - Website Architecture

# Engineering Portfolio Website Structure


---

# 1. Overall Experience


The website should not behave like a traditional resume website.

It should behave like an interactive engineering presentation.


The visitor should experience:

Introduction

↓

Identity

↓

Engineering Journey

↓

Technical Capability

↓

Future Vision

---

# 2. Website Flow


The complete structure:

Loading Experience

↓

Hero Section

↓

Engineering Identity

↓

Journey Timeline

↓

Project Showcase

↓

Technical Skills

↓

International Experience

↓
Contact / Future Collaboration

---

# 3. Section Overview


# Section 01

## Loading Experience


Purpose:

Create the first impression.


Content:

- Logo animation
- Drone initialization
- System startup feeling


Example:

SYSTEM INITIALIZING...

ROBOTICS CORE ONLINE

WELCOME

The loading should feel like:

An engineering system booting.


Avoid:

Game loading screen.


---

# Section 02

# Hero Section


Purpose:

Introduce personal identity.


Main element:

3D Drone


Content:

Yu Jen Lin

Robotics Engineer

Building Intelligent Machines
for the Future.

Interaction:

- Drone floating
- Camera movement
- Mouse interaction
- Scroll transition

# Section 03

# Engineering Identity


Purpose:

Explain who the engineer is.


Content:

Who I am

Text

# 4. Navigation System


Navigation should be minimal.


Desktop:

Logo

About

Projects

Experience

Contact

Style:


Floating transparent navigation.


---

# 5. Responsive Strategy


## Desktop


Primary experience.


Features:

- Full 3D scene
- Camera animation
- Large typography


---

## Tablet


Reduce:

- Particle count
- Model complexity


---

## Mobile


Priority:


Content > Animation


Disable:


- Heavy 3D effects
- Complex camera movement


Keep:


- Clean layout
- Smooth transition


---

# 6. User Journey


The visitor should think:


First 5 seconds:


"Interesting technology website."


After exploring:


"This person builds real engineering systems."


After finishing:


"This engineer has global potential."


---

# 7. Final Architecture Principle


Every section should contribute to one story:

I am an engineer.

I build intelligent systems.

I solve real problems.

I am ready for the future.
