# Engineering Portfolio Design Specification

## Yu Jen Lin - Robotics Engineer Portfolio

> Building Intelligent Machines for the Future.

---

## 1. Project Overview

This document defines the complete design, interaction, technical architecture, and development specification for Yu Jen Lin's personal engineering portfolio website.

The goal is to create a cinematic, interactive, engineering-focused portfolio that represents:

- Robotics Engineering
- Intelligent Automation
- Embedded Systems
- Artificial Intelligence
- Digital Manufacturing
- Mechanical Design
- Future Engineering Development

This is not designed as a traditional developer portfolio.

The website should feel closer to:

- Apple Product Experience
- DJI Technology Showcase
- SpaceX Mission Website
- NVIDIA Engineering Presentation
- Industrial Design Exhibition

The website should communicate:

"An engineer who builds intelligent machines."

---

# 2. Core Objective

The website should achieve three goals:

## 1. Professional Identity

Present Yu Jen Lin as:

- Robotics Engineer
- Automation Developer
- AI / Embedded System Developer
- Future Global Engineer


## 2. Storytelling

The website should tell a personal engineering journey:

From:

Arduino Projects

↓

Robotics Competition

↓

Rocket Development

↓

AI Application

↓

International Experience

↓

Future Engineering Career


## 3. Technical Demonstration

The website itself should demonstrate:

- 3D Graphics
- WebGL
- Interactive Design
- Engineering Thinking
- Modern Frontend Development

The website is not only a portfolio.

The website itself is a project.

---

# 3. Design Philosophy

## Main Concept

"Engineering meets Future Technology"

The visual experience should combine:

- Precision engineering
- Industrial design
- Advanced technology
- Minimal aesthetics


The design should feel:

- Premium
- Professional
- Clean
- Futuristic
- Scientific


Avoid:

- Cartoon style
- Gaming style
- Excessive neon
- Generic portfolio templates
- AI-generated appearance

# 8. Development Principle


Every design decision should answer:

"Does this make the engineer's story stronger?"


Avoid adding effects only because they look impressive.


Technology should support storytelling.


---

# 9. Final Vision


The final website should feel like:

A robotics engineer presenting his future vision.

Not:

A student showing homework.


The visitor should leave with the impression:


"Yu Jen Lin is someone who builds intelligent machines and has the ability to work in a global engineering environment."
